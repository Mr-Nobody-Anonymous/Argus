# ─────────────────────────────────────────────────────────────────────────────
# Argus — optional AI extras
#
#     pip install -r requirements-optional.txt
#
# These packages unlock the advanced vision features. They are intentionally
# kept out of requirements.txt because they are large, slow to build, and
# frequently lag behind new Python releases (several do not yet publish wheels
# for Python 3.12+). Argus detects each one at runtime and falls back to a
# documented degraded mode when it is missing:
#
#   paddleocr / paddlepaddle -> LPR falls back to basic OCR heuristics
#   insightface              -> face recognition falls back to OpenCV detection
#   deepface                 -> emotion detection is disabled
#   mediapipe                -> pose estimation falls back to bbox heuristics
#   anomalib                 -> anomaly detection uses the built-in detectors
#   pytorchvideo             -> video-understanding extras are disabled
#   opencv-contrib-python    -> enables cv2.face LBPH recogniser (see note)
#
# NOTE: opencv-contrib-python conflicts with opencv-python-headless. Install it
# only if you need the LBPH face recogniser and are not running headless.
# ─────────────────────────────────────────────────────────────────────────────
